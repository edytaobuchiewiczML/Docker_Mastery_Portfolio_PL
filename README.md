# Docker_Mastery_Portfolio_PL
Docker Mastery – kompletne repozytorium do nauki Dockera od podstaw po zaawansowane techniki. Zawiera praktyczne przykłady, Dockerfile, docker-compose, zarządzanie wolumenami, sieciami i konteneryzację aplikacji. Idealne dla devopsów i developerów chcących opanować technologię kontenerów.
